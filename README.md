# Amazing EKB Hub Frontend

Frontend для MVP "Гид по местам".

## Стек

- Next.js 16
- React 19
- TypeScript
- Chakra UI 3
- ESLint 9

## Быстрый старт

1. `pnpm install`
2. `pnpm dev`

## Основные команды

- `pnpm lint`
- `pnpm lint:strict`
- `pnpm typecheck`
- `pnpm build`
- `pnpm start`
