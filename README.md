# Amazing EKB Hub — каталог мест Екатеринбурга

Публичный интерфейс городского каталога: посетитель находит места по категориям, просматривает тематические подборки и открывает подробную карточку места. Приложение получает данные из отдельного backend через типизированный API.

## Возможности

- Главная страница, категории, подборки и страницы отдельных мест.
- Постраничная загрузка подборок и последовательная подгрузка списка мест.
- Серверный рендеринг страниц и маршруты для обновления кеша.
- Компоненты на Tailwind CSS и shadcn/Base UI, анимации и адаптивная композиция.
- Клиент API на основе OpenAPI и проверки интерфейса с Vitest.

## Что показывает проект

Разработку контентного продукта на Next.js: маршрутизацию, серверные данные, кеширование и переиспользуемые компоненты. Архитектура FSD разделяет предметные сущности, пользовательские действия и сборку страниц, а типизированный контракт связывает frontend с backend. Это применимо к каталогам, маркетплейсам, медиа и городским сервисам.

## Разработка

Node.js 24, pnpm@11.15.1. Настройки подключения перечислены в [.env.example](.env.example).

```sh
pnpm install
pnpm dev
```

Проверки и production-сборка:

```sh
pnpm lint
pnpm test:unit
pnpm build
```
