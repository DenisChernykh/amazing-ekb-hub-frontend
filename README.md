# Amazing EKB Hub — публичный интерфейс

Публичный frontend каталога мест на Next.js и React.

## Возможности

- Страницы каталога и взаимодействие с backend через API.
- Компоненты Material UI и типизированные модели данных.
- Same-origin API-маршрутизация и автоматизированные проверки.

## Инженерные акценты

- Разделение страниц, пользовательских действий и предметных сущностей по FSD.
- Интеграция frontend с контрактом внешнего backend.
- Работа с серверным рендерингом и библиотекой компонентов.

## Стек

React, Next.js, TypeScript, Tailwind CSS, Vitest.

## Навигация по коду

- [src/](src/) — исходный код.
- [docs/](docs/) — архитектура и документация.

## Разработка

Инструменты: Node.js 24, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
```

Параметры окружения перечислены в [.env.example](.env.example). Локальные значения задаются вне Git.
