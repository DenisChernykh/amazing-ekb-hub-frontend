# Security Baseline

## Env

1. Секреты только через env.
2. `NEXT_PUBLIC_*` только для безопасных публичных значений.
3. `.env` не коммитить.

## UI

1. Не показывать сырые backend errors.
2. Явно обрабатывать `401`, `403`, `500`.
3. Не хранить чувствительные токены в клиенте без необходимости.
4. Пользовательские тексты ошибок берутся из локальных мапперов (`getRemoteFailureMessage`, `getApiIssueMessage`), а не из raw backend `error.message`.
